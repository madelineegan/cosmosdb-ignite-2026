# BRK367 · Azure Cosmos DB resources

Public resource landing page for **Microsoft Ignite 2026 breakout BRK367: Designing the data layer for AI apps and agents with Azure Cosmos DB**.

> Remember deliberately. Act safely. Retrieve appropriately.

## Quick start

```bash
npx skills add AzureCosmosDB/cosmosdb-agent-kit
```

## What is included

- Azure Cosmos DB Agent Kit
- AI agent architecture and implementation guidance
- Agent state and memory patterns
- Agent Memory Toolkit (preview)
- Hosted MCP server (preview)
- RAG, full-text, vector, hybrid search, and semantic reranking
- Azure Cosmos DB gallery
- Cosmos DB + Microsoft Fabric documentation and samples
- Public multi-agent analytics sample

## Run locally

The site has no build step or external runtime dependencies.

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.
